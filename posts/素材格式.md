# 素材格式

从 10/9 起，改为给用户提供素材，用户自己写帖子。每次推送 5–6 条，按"值不值得发"排序。

## 每条素材的格式

```
### 1. 一句话说清是什么事

- 发生了什么：两三句大白话，讲清楚谁、做了什么、结果怎样
- 关键数字：直接能用在帖子里的数字，每个数字后面写出处
- 为什么值得发：流量点在哪（名人、反差、跟华人投资者有关、大家都在聊……）
- 可以聊的角度：两三个方向，只给思路，不写成句子，用户自己发挥
- 背景：读者可能不懂的词、人、事，一两句解释
- 可信度：已核实（多个来源/原始文件）或 只有一个来源（发之前自己再看一眼）
- 来源：链接，优先原始文件和大媒体
```

## 素材类型（10/11 起新增三类）

原有：当天热点、名人持仓变动、圈子八卦、冷知识/反差数据、和钱有关的生活话题

新增：
1. **实用干货**：读者看完马上能用的投资知识——账户、交易成本、规则、工具、怎么看财报某个指标、某个功能怎么用
2. **信息差**：华人投资美股时很多人不知道、但直接影响自己钱的事。例如：美股遗产税、股息预扣税和 W-8BEN、爱尔兰 ETF、国内 QDII 溢价、券商闲置现金利息、盘前盘后规则、期权到期日、公司拆股/分红日期规则
3. **普通人怎么投**：有数据支撑的方法和避坑。例如：定投、指数 vs 主动基金、资产配置、杠杆 ETF 损耗、追高/择时的代价、退休规划

4. **人物故事 + 方法拆解**（10/12 起，用户最喜欢的类型之一）：一个真实的人 + 一个夸张的数字 + 他具体怎么做的。例如：港大学生 Martin Luk 年收益 969.8% 拿美国投资锦标赛冠军 + 回调买入法四步；海龟交易法 400 美元做到 2 亿；护士 255 美元买股票几十年变 46 万；网友 5000 美元买英伟达拿 9 年变 24 万；末日期权账户坐过山车
   - 要素：人是真的、可查的（比赛官网、采访、本人公开账户）；数字越反差越好；方法要拆成几步，读者看完觉得"我也能学"
   - 必须带一句风险：幸存者偏差、比赛成绩不等于普通人能复制、期权/短线大多数人亏钱——素材里写进"可以聊的角度"，让用户自己决定怎么说
   - 适合配一张图（人物 + 收益数字 + K 线标注），在素材里注明"适合配图"以及图上可以放什么
   - 网友晒单类：只用能找到原帖的，标"只有一个来源"

这三类的额外要求（实用干货 / 信息差 / 普通人怎么投）：
- 讲清楚"对读者的钱有什么影响"，最好算一笔账（例如"100 万美元的美股，遗产税最多要交多少"）
- 涉及税务、法律的，标注"不构成税务/法律建议，以专业人士意见为准"，并给出官方或专业机构来源
- 区分读者身份：中国大陆税务居民 / 香港 / 台湾 / 新加坡 / 美国居民，规则常常不一样，写明适用对象
- 这类素材不怕过期，可以作为"常青素材"在新闻少的时候（周末、节假日）多放

## 选素材的标准

- 类型搭配：每批 5–6 条，大致 2 条名人/八卦/反差 + 1 条当天热点 + 1 条人物故事 + 方法拆解 + 1–2 条实用干货/信息差/普通人怎么投；新闻少的时候多放后几类
- 不重复：对照 posts/主题记录.md
- 只有一个小博主说、完全查不到其他来源的，不放；只有一个大号来源的，标"只有一个来源"
- 不替用户下结论，不写成成品句子，不编用户的持仓和经历
- 写作规范（posts/写作规范.md）里关于缩写、术语的要求同样适用：媒体写中文全名，冷门词要解释
